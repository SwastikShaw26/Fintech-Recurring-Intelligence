- **Hosted release.** PostgreSQL and HTTPS browser verification now cover the pilot workflow. Separate database roles, shared gateway protection, backup deletion reconciliation and the Docker image remain open. [Defensive security audit](../engineering-evaluation/security-audit.md)
- **Evaluation.** Frozen holdouts remain stable. Real-data import evidence establishes workflow behavior, while real-world accuracy requires independent recurrence labels. [Test report](../engineering-evaluation/test-report.md)
- **Expansion.** Prioritize forecast confidence and the renewal inbox, then a privacy-preserving import quality center and named account history. [Roadmap](feature-roadmap.md)
