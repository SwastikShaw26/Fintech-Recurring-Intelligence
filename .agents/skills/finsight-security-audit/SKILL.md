# FinSight Security & Privacy Audit Skill

Use this skill to evaluate application security posture, data privacy protections, and supply chain health.

## Instructions
1. Inspect API route definitions, input handling, query parameters, and static file serving.
2. Evaluate privacy considerations regarding sensitive financial transaction records.
3. Review CORS configurations, authentication/authorization boundaries, and dependency vulnerabilities.
4. Classify vulnerabilities by CVSS severity, impact, likelihood, verified evidence, and remediation code.
5. Output findings to `docs/engineering-evaluation/security-audit.md`.
